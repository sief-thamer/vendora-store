# 15 — دليل الإدارة (Admin Guide)

**المشروع:** VENDORA | فيندورا · **الإصدار:** 1.2.0

---

## 1. الدخول إلى لوحة الإدارة
1. افتح `admin.html` (أو من الرابط داخل المتجر إن وُجد).
2. سجّل الدخول بمستخدم إداري، مثال: `admin` / `admin123`.
3. تظهر اللوحة بحسب صلاحية دورك (انظر وثيقة الصلاحيات 10).

## 2. إدارة المنتجات والتصنيفات والعلامات
- **المنتجات:** إضافة/تعديل؛ الحقول: الاسم عربي/إنجليزي، الرابط (slug)، التصنيف،
  العلامة، السعر/سعر المقارنة، الحالة (منشور/مسودة)، مميّز/جديد، الصور، المواصفات.
- **التصنيفات:** شجرة تصنيفات (رئيسي/فرعي) مع أيقونة/لون.
- **العلامات:** الاسم والرابط.

## 3. المخزون
- **مخزون لكل سوق ومستودع**؛ المتاح = الفعلي − المحجوز − غير القابل للبيع.
- **تعديل الكمية:** عبر `adjust` (يزيد/ينقص) مع سبب؛ عند الزيادة تُطلَق تنبيهات التوفّر.
- **حد النقص (low stock):** يظهر تلقائيًا حسب إعداد `lowStockThreshold`.
- **تنبيهات التوفّر:** تظهر في تقرير المخزون (من اشترك بـ«أخبرني»).

## 4. الطلبات
- **العرض والتصفية** حسب الحالة/الدفع/التاريخ.
- **تنفيذ الطلب:** غيّر الحالة بالتسلسل:
  PENDING → CONFIRMED → PROCESSING → READY_TO_SHIP → SHIPPED →
  OUT_FOR_DELIVERY → DELIVERED.
- **الإلغاء:** قبل الشحن مقبول؛ بعده بموافقة المسؤول.
- **الشحن:** إنشاء شحنة + تفاصيل التتبّع.
- **الفاتورة:** زر طباعة الفاتورة من صفحة الطلب.

## 5. الدفع والتحصيل
- **إلكتروني:** يتبع دورة محاكاة حتى «مدفوع» (مهلة 15 دقيقة).
- **تحويل بنكي:** راجع الإيصال ورقم العملية (يُمنع التكرار) ثم:
  قبول → `paid` / رفض / طلب معلومات — خلال مهلة ساعتين.
- **الدفع عند الاستلام:** تحصيل عند التسليم (`collected`).
- **الاسترداد:** يُطلب من مسؤول الطلبات، ويُعتمد من **المدير فقط**.

## 6. المرتجعات والاستبدال
- مراجعة طلب الإرجاع (قبول/رفض)؛ بعد الاستلام يُفحص المنتج قبل إعادته للمتاح.
- ثم إنشاء طلب استرداد واعتماده.

## 7. إدارة التوصيل
- **المدينة/المنطقة:** أضف مدينة لسوق مع: الرسوم، حد الإعفاء، مدة التوصيل
  (من–إلى)، السماح بالدفع عند الاستلام.
- تُربط الرسوم بالمدينة تلقائيًا عند إتمام الطلب (عرض ETA في الدفع).

## 8. الكوبونات والمحتوى
- **الكوبونات:** كود، نوع (مبلغ/نسبة)، حد أدنى، حد استخدام، تاريخ انتهاء، أسواق.
- **المحتوى:** الصفحات الثابتة (عن الموقع، تواصل، الأسئلة، الدليل، الثقة، السياسات).

## 9. المراجعات
- اعتماد/رفض المراجعات المعلّقة.
- تظهر علامة **مُبلَّغ عنه** للمراجعات التي أبلغ عنها العملاء.
- يُدعم وسم **مشترٍ موثّق** لمن اشترى فعليًا.

## 10. العملاء
- عرض العملاء وطلباتهم؛ البحث بالبريد/الاسم.

## 11. الموظفون والصلاحيات
- إضافة موظف وتحديد دوره (وثيقة 10). كل مسار محمي بصلاحية.

## 12. الإعدادات
- بيانات المتجر، تواصل الدعم، حد النقص، السوق الافتراضي، تفعيل COD،
  **طرق الدفع**، سياسات دورة الحياة (مهلة الدفع، مراجعة التحويل، نافذة الإرجاع، حجز).
- **التوصيل:** إدارة المدن/الرسوم.
- **النسخ الاحتياطي:** تصدير JSON / استيراد JSON.

## 13. سجل العمليات (Audit)
- تسجيل كل عملية إدارية (من، ماذا، متى، على أي كيان).

## 14. نصائح تشغيلية (Tips)
- غيّر بيانات الدخول الافتراضية في بيئة حقيقية.
- خذ نسخة احتياطية دورية قبل أي تحديث.
- راجع سجل العمليات دوريًا وتنبيهات المخزون.
