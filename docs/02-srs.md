# 02 — وثيقة متطلبات النظام (SRS)

**المشروع:** VENDORA | فيندورا · **الإصدار:** 1.2.0

---

## 1. المتطلبات الوظيفية (Functional Requirements)

### 1.1 الكتالوج والتصفح
| الرقم | المتطلب |
|---|---|
| FR-CAT-01 | تصفح المنتجات مع فرز/تصفية (تصنيف، علامة، سعر، توفّر). |
| FR-CAT-02 | صفحة منتج بصور، وصف، مواصفات، تقييمات، منتجات مشابهة. |
| FR-CAT-03 | تصنيفات متعددة المستويات (رئيسي/فرعي) وصفحة كل التصنيفات. |
| FR-CAT-04 | علامات تجارية وصفحة لكل علامة. |
| FR-CAT-05 | صفحات: العروض، الجديد، الأكثر مبيعًا. |

### 1.2 البحث
| FR-SRC-01 | اقتراحات بحث فورية منسدلة. |
| FR-SRC-02 | سجل عمليات البحث الأخيرة + البحث الشائع. |
| FR-SRC-03 | صفحة نتائج بحث مع تطبيق نفس أدوات الفرز/التصفية. |

### 1.3 السلة والدفع
| FR-CRT-01 | إضافة/إزالة/تعديل الكمية، حساب الإجمالي (شحن، خصم، ضريبة) حسب السوق/المدينة. |
| FR-CRT-02 | تطبيق كوبون خصم والتحقق من صلاحيته. |
| FR-CRT-03 | المفضلة والمقارنة. |
| FR-CHK-01 | نموذج دفع ببيانات الشحن والمدينة وتقدير موعد التوصيل. |
| FR-CHK-02 | الموافقة الإلزامية على الشروط قبل تأكيد الطلب. |
| FR-CHK-03 | خيارات دفع: إلكتروني (محاكاة)، تحويل بنكي يدوي، دفع عند الاستلام (حسب السوق). |
| FR-CHK-04 | مهلة الدفع الإلكتروني (15 دقيقة) ومهلة مراجعة التحويل (ساعتان). |

### 1.4 الحساب
| FR-ACC-01 | تسجيل/دخول/خروج، تحقق بريد (رمز)، استعادة كلمة مرور. |
| FR-ACC-02 | إدارة العناوين، تحديث البيانات، تغيير كلمة المرور. |
| FR-ACC-03 | حذف الحساب وبياناته. |
| FR-ACC-04 | مركز إشعارات العميل. |
| FR-ACC-05 | قائمة الطلبات وتفاصيل كل طلب وطباعة الفاتورة. |

### 1.5 الطلبات
| FR-ORD-01 | إنشاء طلب بمفتاح Idempotency لتجنب التكرار. |
| FR-ORD-02 | دورة حياة كاملة (انظر UML/BPMN) مع فصل الحالات. |
| FR-ORD-03 | إلغاء: قبل التجهيز مقبول، بعد التجهيز بموافقة المسؤول، بعد الشحن إيقاف/إرجاع. |
| FR-ORD-04 | إرجاع/استبدال مع مراجعة، واسترداد باعتماد المدير حصرًا. |
| FR-ORD-05 | تتبّع الطلب برقم الطلب. |

### 1.6 المخزون
| FR-INV-01 | مخزون مستقل لكل سوق/مستودع/متغيّر. |
| FR-INV-02 | المتاح = الفعلي − المحجوز − غير القابل للبيع. |
| FR-INV-03 | حجز مؤقت عند الدفع/التأكيد، تثبيت عند التأكيد، تحرير عند الإلغاء. |
| FR-INV-04 | «أخبرني عند التوفّر» مع إطلاق الإشعار عند التزويد. |
| FR-INV-05 | حركات مخزون مسجّلة وتنبيهات نقص. |

### 1.7 التوصيل
| FR-DLV-01 | مناطق ومدن لكل سوق مع رسوم وحد إعفاء ومدة تقديرية. |
| FR-DLV-02 | إدارة المدن/المناطق من لوحة الإدارة. |
| FR-DLV-03 | شحنات ومحاولات توصيل وحالات. |

### 1.8 المراجعات والمحتوى
| FR-REV-01 | إضافة مراجعة (بانتظار المراجعة) واعتماد/رفض من الإدارة. |
| FR-REV-02 | شارة «مشترٍ موثّق» لمن اشترى فعليًا. |
| FR-REV-03 | إبلاغ العميل عن مراجعة، وتنبيه الإدارة. |
| FR-CNT-01 | صفحات ثابتة (عن الموقع، تواصل، الأسئلة، الدليل، الثقة، السياسات). |

### 1.9 الإدارة
| FR-ADM-01 | لوحات: الرئيسية، المنتجات، التصنيفات، العلامات، المخزون، الطلبات، المرتجعات، العملاء، الكوبونات، المحتوى، المراجعات، الموظفون، الإعدادات، سجل العمليات. |
| FR-ADM-02 | إدارة الموظفين والأدوار والصلاحيات. |
| FR-ADM-03 | إعدادات المتجر والسياسات وطرق الدفع. |
| FR-ADM-04 | نسخ احتياطي (تصدير JSON) واستعادة (استيراد JSON). |

## 2. المتطلبات غير الوظيفية (Non-Functional)
| الرقم | المتطلب |
|---|---|
| NFR-01 | الأداء: تحميل الصفحات الرئيسية خلال أقل من ثانية على جهاز عادي. |
| NFR-02 | التوافق: متصفحات حديثة (Chrome/Edge/Firefox/Safari). |
| NFR-03 | الاستجابة: تصميم متجاوب كامل (هاتف/تابلت/سطح مكتب). |
| NFR-04 | اللغات: عربي/إنجليزي مع RTL/LTR كامل. |
| NFR-05 | الوضع الليلي والنهاري. |
| NFR-06 | إمكانية الوصول: تسميات ARIA، تباين، تنقّل بلوحة المفاتيح. |
| NFR-07 | الأمان: تخزين كلمة المرور مُجزّأة (Demo)، لا أسرار في الكود. |
| NFR-08 | قابلية النقل: يعمل بلا إنترنت ومن نقر مزدوج. |
| NFR-09 | الموثوقية: لا فقدان للبيانات المحلية عند التحديث (ترحيل نسخة DB). |
| NFR-10 | قابلية الصيانة: بنية خدمية مفصولة (services/pages/components). |
