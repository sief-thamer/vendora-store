# 14 — خطة الإطلاق (Launch Plan)

**المشروع:** VENDORA | فيندورا · **الإصدار:** 1.2.0

---

## 1. بيئات النشر (Environments)
| البيئة | الاستخدام |
|---|---|
| محلي (Local) | تشغيل بنقر مزدوج أو خادم ملفات (`START_VENDORA.bat`, منافذ 8000–8999) |
| تجريبي (Staging) | نسخة للاختبار مع بيانات تجريبية |
| إنتاج (Production) | خادم حقيقي + قاعدة بيانات + إنترنت (خطة مستقبلية) |

## 2. خطوات الإطلاق (Launch Steps) — النسخة المحلية الحالية
1. تسليم ملف `VENDORA.zip`.
2. فك الضغط في مجلد.
3. التشغيل: `START_VENDORA.bat` (أو فتح `index.html` مباشرة).
4. التحقق: المتجر `/`، لوحة الإدارة `admin.html` (ببيانات الدخول المذكورة أدناه).
5. التحقق من دورة طلب كاملة + نسخة احتياطية/استعادة.

## 3. الترتيب الموصى به للإطلاق (Phased)
1. إطلاق تجريبي مُقفل (UAT) مع فريق داخلي.
2. إصلاح الملاحظات وضبط البيانات.
3. إطلاق عام تدريجي بالسوق الافتراضي (YE).
4. إضافة أسواق/لغات تدريجيًا بعد استقرار الأداء.

## 4. المراقبة (Monitoring)
- مراقبة أخطاء الطرفية (Console/Exceptions).
- مراقبة نجاح دورات الطلب والدفع.
- مراقبة حجم/سلامة البيانات المحلية.
- في الإنتاج: لوحات أداء + تنبيهات (Uptime، Error rate، Latency).

## 5. النسخ الاحتياطي والاستعادة (Backup & Restore)
- **النسخ:** لوحة الإدارة → الإعدادات → «النسخ الاحتياطي» → تصدير JSON (39 مخزنًا).
- **الاستعادة:** استيراد نفس الملف → يُطبَّق فورًا (رفض الملف غير الصالح `invalid_backup`).
- **التوصية للإنتاج:** نسخ مجدولة تلقائيًا + نسخ خارج الموقع (Off-site) + اختبار استعادة دوري.

## 6. بيانات الدخول التجريبية (Demo Credentials)
| الجهة | المستخدم | كلمة المرور |
|---|---|---|
| مدير النظام | `admin` | `admin123` |
| عميل تجريبي | `demo@vendora.local` | `demo1234` |

## 7. خطة التراجع (Rollback)
- الاحتفاظ بأحدث نسخة احتياطية سليمة قبل أي تحديث.
- عند الفشل: استعادة النسخة السابقة فورًا (استيراد JSON).
- ضبط `VERSION`/`DB_VERSION` لضمان ترحيل/بذر صحيح عند التحديث.
