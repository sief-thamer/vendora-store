# 11 — وثيقة الأمان (Security)

**المشروع:** VENDORA | فيندورا · **الإصدار:** 1.2.0

> هذا نموذج تعليمي (Demo) يعمل محليًا؛ الإجراءات أدناه تصف ما طُبّق فعليًا وما يجب
> فعله في نسخة الإنتاج.

---

## 1. التهديدات (Threats) والضوابط (Controls)
| التهديد | الضابط المطبَّق | توصية للإنتاج |
|---|---|---|
| سرقة كلمة المرور | تجزئة كلمة المرور قبل التخزين (`utils.hashPassword`) وعدم تسجيلها | استخدام خوارزمية آمنة (bcrypt/Argon2) + Salt |
| كشف الأسرار | لا مفاتيح/اعتمادات في الكود | أسرار عبر متغيّرات بيئة/خدمة أسرار |
| وصول غير مصرّح للوحة | حراسة المسارات + `V.perms.can` | مصادقة خادم + JWT/Session |
| تصعيد صلاحيات | فحص الصلاحية داخل الخدمة للعمليات الحسّاسة (استرداد) | ضبط على الخادم |
| وصول عميل لطلبات غيره | ربط الطلبات بـ `customerId` والتحقق عند العرض | تحقق خادمي لكل طلب |
| تكرار العملية المالية | مفتاح Idempotency + منع تكرار رقم التحويل (`reference_duplicate`) | قيود فريدة على الخادم |
| انتهاء مهلة الدفع | مهلة 15 دقيقة (`payment_expired`) | مؤقّت خادمي موثوق |
| تلف/فقدان البيانات | IndexedDB + نسخ احتياطي قابل للاستعادة (`exportAll/importAll`) | نسخ مجدولة على الخادم |
| بيانات تاريخية مغلوطة | Snapshot للطلب (أصناف/سعر/عنوان) | حفظ Immutable |
| تحقق البريد | رموز تحقق بصلاحية زمنية (`verificationTokens`) | إرسال بريد فعلي + حدّ محاولات |

## 2. إدارة البيانات (Data Handling)
- بيانات محلية على جهاز المستخدم (IndexedDB/localStorage) — لا إرسال لمخدموب خارجي.
- الجلسة في `vendora.session`؛ الخروج يمسح الجلسة.
- كلمة المرور مُجزّأة، ولا تُسجّل في السجلّات.
- فهرسة فريدة لـ: `customers.email`, `products.slug`, `orders.number`, `coupons.code`.

## 3. فصل الحالات والأدوار
- فصل حالات الطلب/الدفع/التحصيل/الحجز/الإرجاع يمنع تضارب المنطق.
- الاعتماد المالي محصور بالمدير (`role_admin`).

## 4. الخصوصية (Privacy)
- جمع الحد الأدنى من البيانات (الاسم، التواصل، عنوان الشحن).
- سياسة خصوصية منشورة في المتجر (`/page/privacy`).
- إمكانية حذف الحساب والبيانات من الملف الشخصي.

## 5. قائمة تحقق الإنتاج (Production Checklist)
- [ ] نقل كل المنطق الحسّاس إلى خادم موثوق.
- [ ] تشفير النقل (HTTPS) وتشفير البيانات الحسّاسة عند التخزين.
- [ ] تجزئة كلمات المرور بخوارزمية آمنة + Salt + Pepper.
- [ ] تقييد المعدّل (Rate limiting) على الدخول/التحقق/الدفع.
- [ ] تسجيل أمني (Security logging) ومراقبة.
- [ ] اختبار اختراق ومراجعة دورية للصلاحيات.
- [ ] نسخ احتياطي مشفّر + خطة استعادة (DR).
- [ ] إدارة أسرار مركزية وتدوير المفاتيح.
