# 07 — وثيقة BPMN (سير العمليات التجارية)

**المشروع:** VENDORA | فيندورا · **الإصدار:** 1.2.0

---

## 1. العملية 1 — الشراء حتى التسليم (Order-to-Delivery)

| الخطوة | المنفّذ | الأدوات/الخدمات |
|---|---|---|
| 1. تصفّح واختيار | العميل | Catalog |
| 2. إضافة للسلة | العميل | Cart |
| 3. إتمام الدفع (بيانات + مدينة + موافقة الشروط) | العميل | Cart/Commerce |
| 4. إنشاء الطلب + حجز مؤقت للمخزون | النظام | Orders + Stock |
| 5. اختيار طريقة الدفع | العميل | Payments |
| 6. تأكيد الدفع (إلكتروني/تحويل/COD) | العميل/الإدارة | Payments |
| 7. تأكيد الطلب (تثبيت الحجز) | الإدارة/النظام | Orders + Stock.commit |
| 8. التجهيز | مسؤول الطلبات | Orders |
| 9. الشحن + إنشاء شحنة | مسؤول الطلبات | Shipments |
| 10. التوصيل + التحصيل (COD) | مندوب | Orders + Collection |
| 11. التسليم | — | Orders(DELIVERED) |
| 12. إشعار العميل عند كل تغيّر | النظام | Notifications |

**بوابات قرار (Gateways):**
- الدفع نجح؟ (إلكتروني) → نعم: مدفوع / لا: فشل أو انتهاء المهلة.
- التحويل مطابق وفريد؟ → نعم: قبول / لا: `reference_duplicate` أو رفض/مزيد معلومات.
- الإلغاء مسموح؟ (قبل التجهيز مقبول، بعده بموافقة المسؤول).

## 2. العملية 2 — الإرجاع والاسترداد (Return & Refund)

| الخطوة | المنفّذ | النتيجة |
|---|---|---|
| 1. طلب إرجاع/استبدال | العميل | `returnRequests(status=requested)` |
| 2. مراجعة الطلب | مسؤول الطلبات | approved / rejected |
| 3. إرجاع فعلي واستلام | المستودع | Order → RETURNED |
| 4. فحص المنتج | المستودع | لا يُعاد للمتاح قبل الفحص |
| 5. طلب استرداد | مسؤول الطلبات | `refundRequests(status=requested)` |
| 6. اعتماد الاسترداد | **المدير فقط** | `managerApproval` + Order → REFUNDED |

## 3. العملية 3 — مراجعة الدفع بالتحويل (Transfer Review)

```
[العميل يرفع الإيصال] -> awaiting_transfer -> awaiting_review
   Admin: accepted  -> paid
   Admin: rejected  -> إشعار بإعادة الإرسال
   Admin: needs_info -> طلب معلومات إضافية
   مهلة المراجعة: ساعتان
```

## 4. العملية 4 — نقص المخزون وإعادة التوفّر (Back-in-Stock)

```
طلب يتجاوز المتاح -> رفض stock_issue (out/low)
العميل يشترك "أخبرني عند التوفّر" -> stockAlerts(status=pending)
المخزون يزيد (adjust +delta) -> fireAlerts -> notifications(status=notified, بلا تكرار)
```

## 5. العملية 5 — اعتماد المراجعات (Review Moderation)
```
العميل يرسل مراجعة -> status=pending
Admin: approve -> status=approved (ظهور + دعم شارة مشترٍ موثّق)
Admin: reject  -> status=rejected
العميل يبلّغ عن مراجعة -> reported=true -> تنبيه للإدارة
```

## 6. مؤشرات قياس العملية (Process KPIs)
- زمن من الشحن إلى التسليم، نسبة فشل التوصيل، زمن مراجعة التحويل،
  زمن معالجة الإرجاع، نسبة الاستردادات، معدل تحوّل السلة إلى طلب.

## 7. مسؤوليات الأدوار (RACI مبسّط)
- **العميل:** الطلب/الدفع/الإرجاع.
- **مسؤول الطلبات:** التجهيز/الشحن/المرتجعات/طلب الاسترداد.
- **المدير:** اعتماد الاسترداد/الإعدادات/النسخ الاحتياطي.
- **المستودع:** المخزون/الفحص/الحركات.
