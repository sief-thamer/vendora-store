## 3. تدفقات المستخدم الأساسية (Key Flows)
1. **الشراء:** تصفح → منتج → سلة → دفع (شحن + مدينة + ETA) → موافقة الشروط →
   اختيار طريقة الدفع → نجاح → تتبّع.
2. **الدفع الإلكتروني:** شاشة مهلة 15 دقيقة → تأكيد محاكاة → «مدفوع».
3. **التحويل البنكي:** عرض بيانات الحساب → إدخال رقم العملية + الإيصال →
   «بانتظار المراجعة» → مراجعة الإدارة (قبول/رفض/مزيد من المعلومات).
4. **الإرجاع:** طلب من صفحة الطلب → «مطلوب» → مراجعة الإدارة → «مقبول» →
   «مرتجع» → طلب استرداد → اعتماد المدير → «مُسترد».
5. **الإدارة — تنفيذ طلب:** PENDING → CONFIRMED → PROCESSING → SHIPPED →
   OUT_FOR_DELIVERY → DELIVERED.
6. **نقص مخزون:** إضافة تنبيه «أخبرني عند التوفّر» → عند التزويد يُرسل إشعار.

## 4. مبادئ التصميم (UI Principles)
- تخطيط RTL/LTR تلقائي، شبكات متجاوبة (Grid/Flex).
- نظام مكوّنات موحّد: بطاقات، أزرار، شرائح، جداول، نوافذ منبثقة، تنبيهات، Toasts.
- حالات واضحة: تحميل، فراغ، نجاح، فشل، خطأ تحقق.
- شارات حالات ملوّنة للحالات (طلب/دفع/تحصيل/حجز/إرجاع).
- شريط علوي: بحث، سلة، مفضلة، حساب، تبديل اللغة/الثيم، سوق.
- مؤشر تقدّم في الدفع وتأكيد فوري للعمليات.

## 5. إمكانية الوصول (Accessibility)
- `aria-label` على العناصر التفاعلية والأيقونات، `role` حيث يلزم.
- تباين ألوان كافٍ في الثيمين، إخفاء بصري سليم، دعم لوحة المفاتيح.

## 6. الاستجابة (Responsive)
- نقاط انكسار للهاتف/التابلت/سطح المكتب؛ أشرطة قابلة للتمرير أفقيًا على الجوال.
