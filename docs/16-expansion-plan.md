# 16 — خطة التوسع (Expansion Plan)

**المشروع:** VENDORA | فيندورا · **الإصدار:** 1.2.0

---

## 1. توسّع الأسواق (Markets)
النهج الحالي يدعم 7 أسواق (YE, SA, AE, KW, QA, BH, OM) بعملات ومنتجات ومخزون
ودفع مستقل لكل سوق. للتوسّع:
- إضافة سوق جديد: سجل `markets` (عملة، منازل عشرية، هاتف، مدن، رسوم، كوبونات، طرق دفع).
- بيانات مخزون/أسعار مستقلة لكل سوق — **بلا تحويل عملات تلقائي**.
- إضافة مستودعات ومناطق/مدن توصيل للسوق الجديد.

## 2. توسّع اللغات (Languages)
- إضافة لغة = إضافة مفاتيح في `V.DICT` (بنية `{ar,en}`) + ضبط الاتجاه (RTL/LTR).
- يدعم النظام الاتجاهين تلقائيًا؛ لغات جديدة تتبع نفس البنية.

## 3. توسّع الموردين والبائعين (Suppliers & Sellers)
- **الموردون:** جدول موردين + ربط المنتجات بالمورد + أوامر شراء.
- **البائعون (Multi-vendor):** ربط المنتجات/الطلبات بمتجر بائع، عمولات، لوحة بائع.
  (يتطلب تحويل المخزون والطلبات لتصبح متعدّدة المالك.)

## 4. توسّع الوظائف (Feature Roadmap)
| الميزة | الوصف |
|---|---|
| تقارير متقدمة | مبيعات/مخزون/عملاء/تحويلات مع تصدير |
| PWA | تثبيت التطبيق + عمل أفضل دون اتصال |
| إشعارات فعلية | بريد/SMS/دفع فعلي |
| برامج الولاء | نقاط ومستويات وتخفيضات |
| توصيات ذكية | «منتجات قد تعجبك» مبنية على السلوك |
| دعم متعدد المخازن | توزيع الطلب بين مستودعات حسب القرب |

## 5. توسّع التقنية (Technical Scale)
- الانتقال من IndexedDB إلى قاعدة بيانات مركزية (PostgreSQL) وخدمة خلفية.
- واجهة برمجية REST/GraphQL + مصادقة آمنة (JWT/OAuth).
- نسخ احتياطي سحابي ومراقبة وتوسيع أفقي (Load balancing).
- فصل الخدمات (Catalog/Orders/Payments) تدريجيًا.

## 6. متطلبات كل توسّع (Requirements per Expansion)
- **بيانات:** مخطط جديد + ترحيل + بذر.
- **صلاحيات:** دور/صلاحية جديدة عند الحاجة.
- **اختبار:** حالات قبول جديدة قبل الإطلاق.
- **وثائق:** تحديث ERD/API/دليل الإدارة.

## 7. مؤشرات جاهزية التوسّع (Readiness)
- استقرار الأداء على السوق الحالي ✔.
- تغطية اختبارات كافية ✔.
- بنية خدمية مفصولة تسهّل الإضافة ✔.
- نمذجة متعددة الأسواق قائمة فعلاً ✔ (نقطة قوة أساسية للتوسّع).
