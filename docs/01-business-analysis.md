# 01 — وثيقة تحليل الأعمال (Business Analysis)

**المشروع:** VENDORA | فيندورا — منصة تجارة إلكترونية شاملة
**الإصدار:** 1.2.0 · **الحالة:** منفَّذ فعليًا (Demo محلي بلا خادم أعمال)

---

## 1. الرؤية (Vision)
منصة تجارة إلكترونية واحدة تخدم عدة أسواق عربية بلغاتها وعملاتها، مع تجربة شراء سهلة
وإدارة مركزية للمنتجات والمخزون والطلبات والتوصيل.

## 2. الأهداف (Objectives)
- عرض منتجات منظّم بمقاسات/تصنيفات/علامات تجارية لكل سوق.
- شراء سلس حتى الدفع، بخيارات دفع متعددة (إلكتروني، تحويل، دفع عند الاستلام).
- إدارة دقيقة للمخزون لكل سوق/مستودع مع حجز مؤقت عند الطلب.
- متابعة كاملة لدورة الطلب والحالات (تجهيز/شحن/توصيل/إرجاع/استرداد).
- إدارة توصيل مرنة (مناطق، رسوم، حد إعفاء، مدة تقديرية) لكل مدينة.
- لوحة إدارة بأدوار وصلاحيات، مع تدقيق (Audit) ونسخ احتياطي قابل للاستعادة.

## 3. نموذج العمل (Business Model)
- بيع مباشر (B2C) بأسعار ثابتة لكل سوق، بلا تحويل عملات تلقائي.
- الشحن رسوم لكل منطقة، ويُعفى عند تجاوز حد معيّن.
- الدفع: إلكتروني (محاكاة داخل النظام)، تحويل بنكي يدوي (بمراجعة)، أو دفع عند الاستلام (COD).
- كوبونات وعروض محدودة المدى.

## 4. السوق الأولي (Initial Market)
- السوق الافتراضي: **اليمن (YE)** — العملة YER، و7 مدن رئيسية منها صنعاء/عدن/تعز.
- أسواق مدعومة: **YE, SA, AE, KW, QA, BH, OM**.
- عملات بثلاث منازل عشرية: KWD, BHD, OMR.

## 5. النطاق (Scope)
**داخل النطاق:** المتجر (واجهة العميل)، السلة والدفع، الحساب، الطلبات، المقارنة/المفضلة،
البحث، المراجعات، صفحات السياسات، لوحة الإدارة الكاملة، التوصيل، النسخ الاحتياطي.
**خارج النطاق:** بوابة دفع حقيقية، خادم خلفي حقيقي، إشعارات بريد/SMS فعلية، بوابات بائعين.

## 6. أصحاب المصلحة (Stakeholders)
| الجهة | الاهتمام |
|---|---|
| العميل | سهولة الشراء والتتبع والإرجاع |
| مدير النظام | التحكم الكامل والإعدادات والنسخ الاحتياطي |
| مسؤول المنتجات/المخزون | دقة الكتالوج والكميات |
| مسؤول الطلبات | تنفيذ الطلبات والحالات والمرتجعات |
| التسويق/الدعم/المحاسب | الكوبونات، المراجعات، التقارير والتدقيق |

## 7. مؤشرات النجاح (KPIs)
- نسبة إتمام الطلبات، متوسط زمن التجهيز، دقة المخزون، زمن معالجة الإرجاع،
  نسبة المراجعات المعتمدة، زمن مراجعة التحويلات البنكية.

## 8. القيود (Constraints)
- يعمل دون إنترنت ومن نقر مزدوج (Vanilla HTML/CSS/JS + IndexedDB/localStorage).
- لا اعتمادات أو مفاتيح حقيقية داخل الكود؛ لا تخزين كلمة مرور نصًّا.
- التخزين المحلي فقط (هذا الإصدار).
