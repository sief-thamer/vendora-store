# 13 — خطة التنفيذ (Implementation Plan)

**المشروع:** VENDORA | فيندورا · **الإصدار:** 1.2.0

---

## 1. نطاق التنفيذ (Delivered Scope)
نُفّذ المشروع فعليًا على عدّة مراحل، وهي الآن **مكتملة** (الحالة ✔):

| المرحلة | المهام | الحالة |
|---|---|---|
| 1 — الأساس والبيانات | `core.js`, `i18n.js`, `db.js` (39 مخزنًا), `markets.js`, `seed.js`, DB v4 | ✔ |
| 2 — خدمات النواة | catalog, cart/commerce, orders, inventory, payments, notifications | ✔ |
| 3 — الحساب | تسجيل/دخول/تحقق/استعادة/عناوين/تغيير/حذف | ✔ |
| 4 — واجهة المتجر | كل صفحات المتجر + السلة/الدفع + ETA + الشروط | ✔ |
| 5 — لوحة الإدارة | كل اللوحات + الحالات الموسّعة + الدفع/الإرجاع/الاسترداد/الشحن + التوصيل + النسخ | ✔ |
| 6 — i18n والهوية | كل المفاتيح + RTL/LTR + الثيمات + التصميم | ✔ |
| 7 — SEO | عناوين/وصف/JSON-LD + robots.txt + sitemap.xml | ✔ |
| 8 — الجودة | اختبارات + لقطات + ضبط | ✔ |
| 9 — التسليم | ZIP + وثائق (هذه الملفات) | ✔ |

## 2. خارطة الطريق المتبقية (Backlog — اختياري)
| الأولوية | المهمة |
|---|---|
| عالية | تحويل طبقة الخدمات إلى API خادم حقيقي + مصادقة آمنة |
| عالية | تكامل بوابة دفع فعلية + إشعارات بريد/SMS |
| متوسطة | تقارير ولوحات تحليلية متقدمة |
| متوسطة | تعدد اللغات (EER/FR) + أسواق جديدة |
| منخفضة | تطبيق PWA + عمل دون اتصال أعمق |

## 3. المهام حسب الوحدة (Tasks by Module)
- **الكتالوج:** CRUD، فلاتر، بحث، مراجعات، مشابهات.
- **التجارة:** سلة، كوبونات، شحن، ضريبة، Idempotency.
- **الطلبات:** حالة/transition، إلغاء، إرجاع، استبدال، استرداد، فواتير.
- **المخزون:** مخزون لكل سوق، حجز/تثبيت/تحرير، حركات، تنبيهات.
- **الدفع:** طرق، إلكتروني، تحويل (إيصالات + مراجعة)، تحصيل، استرداد.
- **الإدارة:** CRUD لكل كيان، صلاحيات، إعدادات، تدقيق، نسخ احتياطي.
- **التجربة:** i18n، ثيمات، استجابة، وصول.

## 4. التقديرات (Estimates — للنسخة الإنتاجية)
| الحزمة | التقدير |
|---|---|
| تحويل الخدمات إلى خادم + قاعدة بيانات علائقية | 4–6 أسابيع |
| تكامل الدفع والإشعارات الفعلية | 2–3 أسابيع |
| التقارير والتحليلات | 2 أسابيع |
| التوسّع (أسواق/لغات/بائعون) | 4 أسابيع |

## 5. المخاطر (Risks) والتخفيف
| المخاطرة | التخفيف |
|---|---|
| تعقيد تعدد الأسواق | نمذجة واضحة لكل سوق (مطبّقة) |
| تناسق المخزون | حجز مؤقت + حركات مسجّلة + فصل المتاح |
| أمان الدفع | Idempotency + مراجعة + اعتماد مدير |
| فقدان البيانات | نسخ احتياطي/استعادة + ترحيل نسخة DB |
