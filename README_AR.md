# VENDORA | فيندورا — متجر إلكتروني شامل

متجر إلكتروني محلي كامل (واجهة متجر + لوحة إدارة) يعمل بالكامل داخل المتصفح، بدون خادم أعمال (No Backend)، وبدون أي إطار عمل خارجي. كل البيانات تُخزَّن محليًا في IndexedDB و localStorage، ويمكن تشغيل الموقع بنقر مزدوج دون إنترنت.

> **الفكرة:** مشروع أكاديمي يوضّح بناء منصة تجارة إلكترونية واقعية (500 منتج، 7 أسواق، عرب/إنجليزي، RTL/LTR) باستخدام HTML5 + CSS3 + JavaScript حديث (Vanilla JS) فقط.

---

## 1) التشغيل السريع

| الطريقة | الخطوات |
|---|---|
| **الأسهل (موصى به)** | انقر مزدوجًا على **`START_VENDORA.bat`** ثم افتح الرابط الذي يُطبع (مثال: `http://localhost:8000/`). للإيقاف: **`STOP_VENDORA.bat`**. |
| المتجر مباشرة | افتح `index.html` في المتصفح (يعمل حتى بدون خادم في معظم الحالات). |
| لوحة الإدارة | افتح `admin.html` (يُفضّل عبر الخادم المحلي). |
| صفحة الاختبارات | افتح `tests.html` لعرض نتائج اختبارات النظام (48 اختبارًا). |

> الخادم المحلي يبحث تلقائيًا عن منفذ حر بين `8000` و`8999`، ويحفظ حالته في `%TEMP%\VENDORA\state.json`.

## 3) المزايا الرئيسية

### واجهة المتجر
- الرئيسية، التصنيفات، البحث، العروض، وصل حديثًا، الأكثر مبيعًا، صفحات العلامات التجارية.
- صفحة منتج غنية (مواصفات، ضمان، سياسة إرجاع، مراجعات، منتجات مشابهة).
- سلة وشراء **الدفع عند الاستلام (COD)**، مع كوبونات، شحن، وضريبة حسب السوق.
- المفضلة (Wishlist)، المقارنة (Compare)، تتبّع الطلب، الحساب والطلبات.
- صفحات: دليل المشتري `/guide`، الثقة والأمان `/trust`، من نحن، تواصل، الأسئلة الشائعة، صفحات سياسات.
- تبديل اللغة (عربي/إنجليزي) مع RTL/LTR، والوضع الفاتح/الداكن، و7 أسواق بعملات مختلفة.

### لوحة الإدارة (`admin.html`)
| المجموعة | الصفحات |
|---|---|
| نظرة عامة | لوحة التحكم (KPIs + رسوم بيانية) |
| الكتالوج | المنتجات، إضافة/تعديل منتج (أسعار لـ7 أسواق)، التصنيفات، العلامات التجارية، المخزون |
| المبيعات | الطلبات، تفاصيل الطلب (تحديث الحالة + الخط الزمني)، الإرجاع، العملاء |
| التسويق | الكوبونات، المحتوى، المراجعات |
| النظام | الموظفون، الإعدادات، سجل العمليات (Audit) |

- حماية بالصلاحيات: كل صفحة محميّة حسب دور المستخدم (`perms.can`), ودخول الموظفين منفصل عن دخول العملاء.
- العمليات الأساسية مُسجّلة في سجل العمليات، مع فترة سماح للمخزون و`stockDeducted/stockRestored` لمنع الحصم المزدوج.

## 5) المعمارية التقنية

- **بدون أطر عمل:** JavaScript خالص (ES5-safe: بلا `optional chaining`)، وحدات نمط IIFE تصدّر واجهة `window.V`.
- **طبقة البيانات:** IndexedDB (`vendora_db`) عبر غلاف `V.db` (tx/get/getAll/put/add/del/byIndex…)، مع localStorage للتفضيلات (لغة/ثيم/سوق/جلسة/سلة).
- **البذرة الحتمية:** 500 منتج تُولَّد بخوارزمية بذرة ثابتة (`mulberry32`, SEED=20260101) → نفس البيانات في كل تشغيل.
- **الأسواق:** 7 أسواق (YE/SA/AE/KW/QA/BH/OM) بعملاتها وضرائبها وشحنها وأسعارها المستقلة، ودعم 3 منازل عشرية (KWD/BHD/OMR).
- **الأحداث:** ناقل أحداث `V.bus` (`state:*`, `cart:changed`, `auth:changed`, `market:changed`, `catalog:loaded`…).
- **الراوتر:** `V.router` قائم على الـhash يدعم المعاملات (`/product/:slug`).
- **i18n:** قاموس `V.DICT` ثنائي اللغة + أيقونات SVG مدمجة `V.ICONS`.
- **دورة حياة الطلب:** `PENDING → CONFIRMED → PROCESSING → SHIPPED → DELIVERED` + مسار الإرجاع، مع حصم المخزون مرة واحدة عند التأكيد واستعادته عند الإلغاء/الإرجاع.

## 7) ملاحظات

- الموقع يعمل **بالكامل دون إنترنت** (كل الأصول: خطوط، أيقونات، صور — محلية).
- **الهوية البصرية:** لوحة كحلي/ذهبي فاخرة مستوحاة من تصميم متاجر Salla (مرجع التخطيط: `rashof.com/ar`)، وشعار «فيندورا» مستخرَج آليًا من بطاقات العلامة الأصلية (PNG) ومحفوظ في `assets/logos/`.
- **صور المنتجات:** 56 صورة حقيقية عالية الدقة (1000×1000) محلية في `assets/images/products/real/` موزّعة على التصنيفات — يمكن استبدالها لاحقًا بمجموعة كاملة.
- المتصفحات المدعومة: Chrome/Edge/Firefox الحديثة (تحتاج دعم IndexedDB).
- لإعادة تعيين البيانات التجريبية: من لوحة الإدارة → الإعدادات → «إعادة تعيين البيانات التجريبية».
- لا تُخزَّن أي بيانات على أي خادم؛ كل شيء محلي في متصفحك.
